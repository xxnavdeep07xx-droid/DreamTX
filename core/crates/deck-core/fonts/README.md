Copied verbatim from a Debian/Ubuntu system font package
(`fonts-dejavu-core` / `fonts-dejavu-extra`).

These fonts power the layout solver's font metrics (and future PDF
embedding). M2 will add subset CJK fonts (Noto Sans SC, OFL) for full-width
CJK metrics and Unicode PDF export.
